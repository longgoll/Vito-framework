Fast HTTP Request Engine

Zero-dependency parser for GET, POST, PUT, DELETE with automatic query parameters, header, and payload body extraction.

Dynamic Routing & Grouping

Segment matching (:id), multi-level path parameters, and modular prefix grouping with app.group().

Rich Middleware Ecosystem

Official chainable plugins for CORS, Logger, Static Files, Rate Limiting, JWT Auth, SSE, and Security Headers.

Native TLS 1.3 & Protocols

Built-in TLS encryption, HTTP/2 multiplexing, and HTTP/3 QUIC (UDP) transport engine.

Edge Runtime & WASM

Serverless WebAssembly adapter for Cloudflare Workers & AWS Lambda with < 1ms cold start time.

Real-Time WebSockets & Job Queue

Full-Duplex WebSockets with Rooms, Heartbeats, Deflate compression, Async Event Bus, and Redis Job Queue with Retries & DLQ.

Prometheus Metrics & DX Tooling

Native Prometheus /metrics endpoint, W3C OpenTelemetry Tracing, ultra-fast in-memory test injector, DB isolation fixtures, and vit doctor diagnostics.

Developer Tooling & CLI

Hot Module Reloading (vit dev), code generators (vit g controller), project scaffolding (vit create), and single binary compilation (< 5MB).

🚀 4 Strategic Pillars of Vito

⚡ 1. LLVM Native Benchmark

Direct LLVM Native Machine Code compilation. Completely eliminates GC pauses & V8 runtime overhead, outperforming Node.js (Express/Fastify), Go (Gin), and approaching C++20.

🤖 2. AI-Native Token Streaming

Built-in vito/sse package with specialized Server-Sent Events helpers for OpenAI, Claude, and Local LLM token streaming out-of-the-box.

🛡️ 3. Auto Swagger UI & OpenAPI

Automatically generates /openapi.json spec and interactive Swagger UI at /docs directly from route definitions without manual annotations.

📦 4. Batteries-Included Ecosystem

Ships with 27 official packages (vito/orm, vito/auth, vito/upload, vito/websocket...). Zero dependency rot and unified code quality.

💡 Cú Pháp Mạch Lạc - Hiệu Năng Vượt Trỗi

So sánh cú pháp Vito với Express, Gin và Actix-Web khi định tuyến API & gom nhóm route.

vitVito (VIT Native)
⚡ 245,100 req/s💾 18.69 MB RAM (100k conns)
import { createApp, Request, Response } from "vito/src/vito.vit";

function main(): number {
    let app = createApp();

    // 1. Dynamic path parameter
    app.get("/users/:id", (req: Request, res: Response) => {
        let userId = req.param("id");
        res.json("{\"status\":\"ok\", \"user_id\":\"" + userId + "\"}");
    });

    // 2. Modular Route Grouping
    app.group("/api/v1", (v1) => {
        v1.get("/products/:category", (req: Request, res: Response) => {
            let cat = req.param("category");
            res.json("{\"category\":\"" + cat + "\"}");
        });
    });

    app.listen(8888);
    return 0;
}
